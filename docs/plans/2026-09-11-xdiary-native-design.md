# xdiary 原生 macOS 应用设计

## 目标

xdiary 是一款可以直接双击运行的 macOS 日记应用。界面和数据逻辑全部使用 SwiftUI 与 Foundation，不加载网页，也不依赖浏览器或本地服务器。

## 方案选择

- **采用：Swift 6 + SwiftUI 原生应用。** 与 macOS 的窗口、菜单、文件面板、快捷键、辅助功能和字体渲染自然一致，包体积小。
- **未采用：Tauri。** 虽然能生成 `.app`，主界面仍由 WebView 渲染，和“不是网页”的要求不一致。
- **未采用：Electron。** 同样使用网页渲染，并附带完整浏览器运行时，体积更大。

## 界面

应用使用 1100 × 760 的默认窗口，最小尺寸 860 × 600。左侧是固定宽度的月份导航：年份和月份使用 DisclosureGroup，启动时全部折叠；展开后显示已有日记日期。底部放置“模板管理”和“导入与导出”。右侧上方显示当前日期、前后一天、回到今天和月历入口；中间按照日记所保存的模板快照渲染填写项。

全局正文、标签、按钮标题使用 14pt。按钮和输入栏工具按钮统一 28pt 高度。颜色使用暖白、浅灰绿和克制的深绿强调，保持 Codex 应用的安静、简约感。模板编辑页由模板列表、内容块编辑器和实时预览组成，支持三级标题、单行文字、多行文字、数字、评分、上下移动、复制、删除和设为默认。

## 数据与保存

每个日期最多一篇日记。日记第一次填写时保存完整模板快照，因此以后修改或删除模板不会改变历史内容。应用状态以版本化 JSON 保存在 `~/Library/Application Support/xdiary/xdiary-data.json`，每次修改通过临时文件原子替换；写入成功后才显示“已保存”。写入失败时保留内存内容，提供重试和应急导出。

完整备份使用结构清晰、严格校验的 JSON，可导入另一台 Mac 的 xdiary。导入前显示新增日记、冲突日记、新模板和冲突模板数量；同日期冲突由用户选择保留本机或使用备份。Markdown 支持本周、上周、本月、全部和自定义范围，按日期、标题、问题与回答组织，适合直接交给 AI 阅读。

## 原生交互

“导入备份”和“导出”调用 macOS 的 NSOpenPanel / NSSavePanel。菜单栏提供新建今天日记、前一天、后一天、模板、导入、完整备份和 Markdown 导出等命令。关闭窗口前若有尚未写入磁盘的内容，应用阻止静默退出并提示保存或导出。

## 验证

核心测试覆盖日期边界、默认模板、模板快照、JSON 往返与非法输入、导入冲突和 Markdown。应用层测试覆盖自动保存状态、保存失败保留内容、日期切换和模板编辑。最终构建 `dist/xdiary.app`，验证签名、Info.plist、可执行文件、首次启动、实际填写、重启恢复、导入导出和界面尺寸。
